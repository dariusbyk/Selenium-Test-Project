# Автоматизированное тестирование веб-приложения с использованием Selenium

Автор: Дабулявичюс Дарюс

Группа: 4П4.23

---

## Описание

Учебный проект автоматизированного тестирования интернет-магазина OpenCart на C# с использованием Selenium WebDriver и NUnit. Содержит шесть тестов для проверки авторизации, регистрации и поиска товаров. Результаты сохраняются в HTML-отчёт, а при падении тестов создаются скриншоты.

## Требования

- Windows.
- Visual Studio 2022 версии 17.8 или новее.
- .NET 8 SDK.
- Google Chrome.
- Доступ к интернету.

Пакеты Selenium, NUnit и остальные зависимости восстановятся через NuGet при сборке проекта. ChromeDriver при необходимости загрузится автоматически через Selenium Manager при первом запуске тестов.

## Запуск

1. Скачайте репозиторий.

2. Откройте файл решения в Visual Studio и соберите его.

3. Запустите RunTests.cmd из папки проекта.

4. После выполнения откройте Reports/report.html для просмотра результатов. Предыдущие отчёты удаляются перед новым запуском.

## Тест-кейсы

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Вход с корректными данными заранее созданного аккаунта | Открывается личный кабинет, отображается ссылка выхода |
| 2 | Вход с существующим email и неправильным паролем | Появляется сообщение об ошибке, вход не выполняется |
| 3 | Регистрация с новым уникальным email | Открывается страница подтверждения создания аккаунта |
| 4 | Регистрация с уже зарегистрированным email | Появляется сообщение, что email уже зарегистрирован |
| 5 | Поиск по запросу `MacBook` | Найден товар `MacBook`, названия всех результатов содержат запрос |
| 6 | Поиск по несуществующему названию | Карточки товаров отсутствуют, отображается сообщение об отсутствии результатов |

## Примечание

На сайте https://demo-opencart.ru/ с помощью данного приложения была обнаружена проблема авторизации:
после отправки корректных данных поля очищаются, но вход не выполняется.
Поведение воспроизводится вручную и через Selenium.
Поэтому тест успешного входа завершается тайм-аутом.

Остальные тесты проходят успешно.
